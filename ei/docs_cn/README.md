# 统一 IsOS 仓库中的 EI 文档

[English](../docs/README.md) · [IsOS 文档](../../docs_cn/README_cn.md)

EI（Embodied Intelligence）源码位于 `ei/`。IsOS 负责配置、图修订、软件包准入和启动；EI 负责智能运行时及其本地安全检查。EOS 负责执行器准入和硬件执行。当前 EI 代码仍包含部分 EGIA 命名的兼容路径；目标是在协调的契约迁移中移除它们。[统一计划](../../ARCHITECTURE-QUESTIONS.md)记录了这一边界。

请从当前的 [EI 总览](../../docs_cn/ei/README_cn.md)、[构建与运行指南](../../docs_cn/ei/develop/build-and-run_cn.md)、[核心模块](../../docs_cn/ei/core/modules_cn.md)和 [IsOS 配置接口](../../docs_cn/ei/interfaces/isos-config_cn.md)开始。此子目录中的旧 EGIA 布局和资格验证文档保留为注明年代的证据；当前所属文档以根目录的 `docs_cn/ei/` 为准。
