# 当前运行日志游标

[English](../../../../docs/isos/develop/owner/log-cursors.md) · [调试](../../debug/troubleshooting_cn.md)

日志游标对客户端不透明，并绑定一个来源和运行。服务器在读取前检查版本、来源、运行 ID、偏移和边界。过期或伪造游标返回结构化错误，绝不指向新运行的记录。合并日志仅包含经过验证的所有者事件；原始子进程流仍是诊断内容。

| 字段 | 类型 / 单位 | 用途与验证 | 缺省值 |
| --- | --- | --- | --- |
| `cursor` | 不透明字符串 / 后续位置 | 以服务器完整性检查编码来源、运行和偏移。 | 首次读取可省略。 |
| `limit` | 正整数 / 条记录 | 限制单次响应；服务器实施最大值。 | 服务器默认值。 |
| `source` | 注册字符串 / 流 | 一个所有者来源或合并流。 | 必填。 |
| `run_id` | 有界字符串 / 运行 | 必须匹配当前选中运行。 | 后续读取必填。 |
