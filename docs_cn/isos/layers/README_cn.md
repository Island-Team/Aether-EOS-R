# 已注册 IsOS 类型目录

**核心**拥有执行，**层**组织主要领域，**组**命名类型族，**节点**是配置后的实例。[注册类型](../interfaces/nodes/type_cn.md)固定位置、端口、能力、设置和生命周期；保存实例选择值。

- [受管组件](process/managed-component_cn.md)描述 IsOS 拥有的进程类型族：已验证软件包入口作为 IsOS 直接子进程监管，并检查归属方就绪及停止。
- [视觉面板消费者](ui/vision-panel_cn.md)描述 UI 所属节点如何引用输出端口并选择渲染方法。IsosUI 拥有布局和订阅；IsOS 不渲染负载。

软件包贡献类型使用相同的[通用节点契约](../interfaces/nodes/README_cn.md)及[软件包验证](../interfaces/packages/README_cn.md)。本目录解释角色；字段级权威仍归这些契约。
