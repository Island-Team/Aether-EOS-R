# Vision 面板消费者

本页说明可以引用已应用图输出的 IsosUI 归属 Vision 节点。这里列出它，是为了帮助读者理解 core → layer → group → node 图层级；IsOS 本身不注册或渲染此 UI 类型。所选软件包或归属方目录必须提供注册类型声明。

图引用标识源节点路径及输出端口。IsOS 有纯[数据选择器](../../interfaces/ui/selection_cn.md)，但当前[展示路由](../../develop/http/presentations_cn.md)因没有归属方发布已验证的公开描述符而返回 503。IsosUI 拥有布局和订阅生命周期；生产者拥有负载字节与端点授权。关闭面板不会停止生产者。
