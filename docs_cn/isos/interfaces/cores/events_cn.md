# 所有者事件契约

[English](../../../../docs/isos/interfaces/cores/events.md) · [设计](../../design/server_cn.md)

已实现的私有事件输入是来自选中所有者进程的有界 JSON 对象。IsOS 在共享记录前检查选中的管道、生产者角色、核心、已准入节点路径和活动 `run_id`。重复或未知键、格式错误或过大行，以及不在所有者策略中的代码均被拒绝。此输入**没有** `schema_version` 或 `graph_revision` 字段；它们属于其他边界。

| 字段 | 类型 / 单位 | 用途与验证 | 缺省值 |
| --- | --- | --- | --- |
| `timestamp` | 字符串 / 时间 | 生产者时间戳，验证后保留。 | 必填。 |
| `level` | 字符串 / 严重程度 | `event_code` 允许的级别。 | 必填。 |
| `source`, `core` | 字符串 / 身份 | 必须匹配选中进程角色及核心。 | 必填。 |
| `node_path` | 字符串或 null / 图路径 | 存在时必须为此所有者已准入。 | 可选，缺省 null。 |
| `event_code` | 字符串 / 事件身份 | 必须属于编译的所有者策略。 | 必填。 |
| `run_id` | 字符串 / 运行 | 必须匹配活动运行。 | 必填。 |
| `correlation_id` | 字符串或 null / 身份 | 关联相关操作。 | 可选，缺省 null。 |
| `message` | 有界字符串 / 文本 | 净化后的诊断。 | 必填。 |
| `fields` | JSON 对象 / 代码特定 | 重复键或不允许的字段导致拒绝。 | 可选，缺省空对象。 |
