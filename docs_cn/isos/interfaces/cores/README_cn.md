# 核心归属方契约

这些页面供接受 IsOS 已准入节点的核心使用。核心拥有执行、生命周期适配器、健康状态和物理安全；IsOS 在交接前验证精确软件包字节、注册位置和运行围栏。以下交换承载有界身份与结果，不承载软件包特有场景或设备语义。

- [设置](setup_cn.md)告知核心就绪前必须读取哪个已验证图和配置。
- [交接](handoff_cn.md)将声明的进程、可执行文件、资源、归属方、运行 ID 和修订绑定到一次归属方接受。
- [事件](events_cn.md)将归属方状态报告给 IsOS，并携带足够身份以拒绝过期观察。
- [控制授权](control-grants_cn.md)传递归属方范围内的控制许可；图边本身不能授予驱动权。
- [依赖停止](dependent-stop_cn.md)要求终止证据，IsOS 才会将停止视为完成或允许替换。

私有管理器 IPC 和服务配置位于[开发](../../develop/owner/README_cn.md)。
