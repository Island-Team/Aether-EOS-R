# UI 节点边界

这些页面面向 IsosUI 的生产者与消费者。图为每个 UI 节点提供注册类型和类型化端口。IsOS 当前通过节点输出接受带运行围栏的按键状态事件，并可从注册输出类型选择展示元数据；生产者拥有负载字节及端点授权。

- [节点事件](node-events_cn.md)定义首个控制输入的认证按键状态请求、激活顺序和图拥有的运动设置。
- [选择](selection_cn.md)定义 UI 选择输出展示方式时的编解码器、媒体、模式、负载与运行围栏检查。
- [呈现](presentation_cn.md)定义 UI 可展示的归属方描述符与输出身份；它不授予私有端点。
