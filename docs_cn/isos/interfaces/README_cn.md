# 节点、软件包、核心与 IsosUI 接口

本目录为连接节点与 IsOS 的作者提供外部契约。**注册类型**声明位置、设置、端口和生命周期；**实例**选择该类型并提供值。**核心**拥有执行权。**精确锁定**标识一个已验证的软件包发行。**运行围栏**组合运行身份与保存图修订，使延迟事件不能影响替代运行。IsOS 当前按这些契约准入图声明和软件包；运行时传输仍由选中归属方负责。

- [节点](nodes/README_cn.md)定义所有节点族共用的类型、实例、端口、数据类型、选择器和边规则。发布类型或连接图时从此开始。
- [软件包](packages/README_cn.md)定义精确发行、声明资源、进程和验证。发布者可据此贡献节点类型，而不需要 IsOS 中的软件包专属逻辑。
- [核心](cores/README_cn.md)定义设置、进程交接、事件、授权和终止停止的归属方交换。核心作者据此接受已验证工作并报告结果。
- [UI](ui/README_cn.md)定义节点输入事件和通用呈现选择。IsosUI 用这些边界发送用户信号并展示归属方输出。

私有管理器 IPC、本地 HTTP 路由细节和源码工作流程见[开发](../develop/README_cn.md)。[控制路径说明](../design/control-path_cn.md)展示这些通用契约的一种组合。
