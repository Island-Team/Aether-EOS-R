# 通用软件包贡献

本目录供软件包发布者及核心作者使用。IsOS 当前对每个软件包采用相同的精确锁定和已验证字节流程；`kind` 只是描述性元数据。软件包通过 `node_contributions` 贡献注册节点类型、资源、进程、数据类型及可选节点集。归属核心在就绪前验证负载特有语义。

- [发行](release_cn.md)定义软件包身份、版本、来源、工件和贡献封套；发布者从此开始。
- [资源](resources_cn.md)定义实例无需猜测路径即可选择的稳定 ID、类别、展示元数据、包含文件和摘要。
- [进程](process_cn.md)定义归属方运行进程的入口、生命周期适配器、主机输入和资源引用。
- [验证](verification_cn.md)解释图发布或启动前进行的精确锁定、文件、目录和归属方能力检查。

[注册节点契约](../nodes/README_cn.md)对软件包及内置节点使用相同的类型和端口规则。[核心交接](../cores/handoff_cn.md)把已验证进程绑定到一个运行及修订。
