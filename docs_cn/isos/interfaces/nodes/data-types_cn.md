# 节点数据类型

本契约供生产者、消费者和 IsosUI 渲染器使用。发布贡献或核心目录只声明一次数据类型；注册[端口](ports_cn.md)引用其 `id`。IsOS 当前验证声明，并按准确的数据类型身份准入边。生产者拥有负载字节与授权。

| 字段 | 类型／单位 | 含义与验证 | 缺失／默认值 |
| --- | --- | --- | --- |
| `id` | 非空字符串／类型 ID | 供端口和边使用的稳定身份。 | 必填。 |
| `version` | 非空字符串／模式版本 | 本负载含义的版本，与软件包及 HTTP 版本独立。 | 必填。 |
| `purpose` | 非空字符串／展示文字 | 解释消费者可如何使用该值。 | 必填。 |
| `media_type` | 非空字符串／MIME 类型 | 描述表现形式；消费者还必须检查编解码器及模式。 | 必填。 |
| `codec` | 非空字符串／编码 ID | 标识准确编码，例如 JSON、UTF-8、图像、像素或音频编码。 | 必填。 |
| `schema` | JSON 对象／负载结构 | 归属方定义结构化值或平面的形状及单位。 | 必填。 |
| `max_payload_bytes` | 1–100,000,000 的整数／字节 | 在呈现或传输前限制单个编码负载。 | 必填。 |

同一组字段可描述记录、文本、时间序列、图像、像素平面、深度、检测和音频。渲染器只在检查注册端口、编解码器、媒体类型、模式、大小上限及自身能力后选择方法；[UI 选择](../ui/selection_cn.md)说明此过程。类型名称本身不授权解码。
