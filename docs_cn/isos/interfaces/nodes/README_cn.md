# 通用节点契约

本目录面向类型发布者、图作者及 UI 开发者。IsOS 当前对 UI 生产者、桥、原语绑定、硬件和软件包进程使用同一声明模型。类型描述允许的行为；实例选择值并连接声明的端口。

- [注册类型](type_cn.md)定义归属位置、生命周期、能力、设置、端口和桥接权限；注册时一次性验证这些声明。
- [实例](instance_cn.md)定义保存的身份、精确软件包锁定、所选设置和输入引用；准入时依据类型检查。
- [端口](ports_cn.md)定义数据类型、传输、交付模式、连接数和速率声明；锚点表示此契约而不是 URL。
- [数据类型](data-types_cn.md)定义编解码器、媒体类型、模式和负载上限，控制信号及可呈现输出共用。
- [设置与选择器](selectors_cn.md)定义通用 JSON 值类别和提供者支持的选项，编辑器无需节点专属表单规则。
- [边](edges_cn.md)定义类型化引用以及通信方式与归属方之间的显式桥。
