# 保存的节点实例

本契约供图作者选择注册类型并连接其端口。IsOS 当前按 `core → layer → group → node` 保存实例，并依据选中类型准入。实例提供身份和选择，不重新定义端口或归属权。参见[类型](type_cn.md)、[设置](selectors_cn.md)和[边](edges_cn.md)。

| 字段 | 类型／单位 | 含义与验证 | 缺失／默认值 |
| --- | --- | --- | --- |
| `version` | 准确字符串／图模式 | 当前图使用 `0.1.0`。 | 必填。 |
| `cores` | 对象／核心 ID | 归属核心的根映射；键是稳定 ID。 | 必填。 |
| `layers`、`groups`、`nodes` | 嵌套对象／路径组成部分 | 将实例置于类型声明的位置。 | 用到的每层必需。 |
| `id` | 字符串／局部节点 ID | 必须与 `nodes` 映射的键一致。 | 必填。 |
| `node_type` | 字符串／注册类型 ID | 选择一种类型及其设置、端口、生命周期和归属方。 | 必填。 |
| `package` | `{id,version}`／精确发行锁定 | 为软件包贡献类型选择已验证字节，不隐式选择最新版。 | 软件包贡献类型必填。 |
| `settings` | 对象／声明的值 | 只允许类型声明的名称和值类别；省略值使用声明默认值。 | 所有设置均允许省略时可选。 |
| `inputs` | 对象／端口引用 | 每个键是声明的输入；值指定源节点与输出。 | 无输入连接时为空。 |
| `references` | 对象／声明的节点路径 | 在准入时解析非端口依赖。 | 无声明引用时为空。 |

图保存稳定资源 ID，不保存可执行文件或工件路径。IsOS 在准入时解析精确锁定及已验证资源字节，并在 Apply 前检查当前修订。Run 和 Restart 重新检查字节。图不携带 HTTP 端点或授权令牌。
