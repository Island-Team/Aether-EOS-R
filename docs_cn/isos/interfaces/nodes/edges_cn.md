# 图的边

本页供图作者连接已注册节点端口。IsOS 当前只在源和目标都存在于已保存图、注册位置与端口一致、声明的数据及传输兼容时准入连接。图存储引用，不存储端点 URL 或访问授权。

输入映射到 `{"node":"core/layer/group/node","output":"port"}`；声明允许多个连接的输入可包含此类引用数组。`node` 是规范的四段路径，`output` 是源节点的输出端口名称。目标键是已注册输入端口名称。缺失节点、未声明端口、重复输入、数据类型／传输／交付模式不匹配或环都会产生带图路径的准入诊断。跨核心传输要求显式声明的桥接能力。[端口](ports_cn.md)是连接数和通信方式的权威来源。

首个键盘控制路径中，生产者的按键状态输出连接 IsOS HTTP 网关，再连接 EOS HTTP 网关，随后连接类型化原语绑定和硬件。每条连接在图中可见；[设计说明](../../design/control-path_cn.md)解释运行行为。桥在自己的边界转换通信方式；任意跨核心边不会悄悄变成 HTTP。
