# 已注册节点类型

本契约供软件包发布者和核心作者定义可复用节点。IsOS 当前在准入实例前验证注册声明；声明拥有归属位置、设置、端口、生命周期和能力。实例不得扩大这些声明。参见[实例](instance_cn.md)、[端口](ports_cn.md)和[选择器](selectors_cn.md)。

| 字段 | 类型／单位 | 含义与验证 | 缺失／默认值 |
| --- | --- | --- | --- |
| `id` | 非空字符串／带版本的类型标识 | 在合并后的核心及软件包目录中标识声明；重复 ID 导致歧义。 | 必填。 |
| `core`、`layer`、`group` | 非空字符串／图路径组成部分 | 固定实例唯一合法的位置。 | 必填；不推断归属方。 |
| `kind` | 非空字符串／节点类别 | 供发现和展示使用，不授予能力。 | 必填。 |
| `description` | 非空字符串／展示文字 | 向编辑器用户解释节点，不授予能力。 | 必填。 |
| `lifecycle` | 非空字符串／归属方生命周期 ID | 告知所选核心如何启动和停止节点。 | 必填。 |
| `capabilities` | 非空字符串数组／能力 ID | 声明归属方必须支持的功能；出现 `bridge` 字段时必须包含 `bridge` 能力。 | 必填；可为空数组。 |
| `settings` | 设置声明数组 | 定义实例可接受的全部值、类型、默认值和选择器；重复名称无效。 | 必填；可为空数组。 |
| `inputs`、`outputs` | 端口声明数组 | 声明全部可连接输入和输出；每个方向内部名称唯一。 | 必填；可为空数组。 |
| `bridge` | 对象／适配器声明 | 指定允许的传输适配器及公开端口；所列端口都必须已声明。 | 可选；缺失表示没有桥接权限。 |

类型契约是通用的：UI 生产者、HTTP 网关、原语绑定和硬件节点使用相同字段。归属方定义执行语义。IsOS 检查结构和图位置，不解释硬件负载。[数据类型](data-types_cn.md)说明端口承载的数据，[边](edges_cn.md)说明端口如何连接。
