# 操作软件包

先搜索或检查目录元数据，再安装或链接精确 `{id,version}` 发行包。安装不在保存的图中选择软件包，也不启动进程。图实例记录精确锁定及稳定资源 ID。先 Validate，再执行带修订检查的 Apply；Run 和 Restart 重验同一发行包、载荷、注册类型、资源、所有者及生命周期能力。只有保存和活动引用均消失后才移除软件包。参见[发行包](../interfaces/packages/release_cn.md)、[验证](../interfaces/packages/verification_cn.md)及[资源](../interfaces/packages/resources_cn.md)。

操作失败不更改保存的图字节或活动运行；参见[软件包拒绝](../debug/troubleshooting_cn.md)。
