# 未完成工作

本清单供贡献者跟踪当前 IsOS 构建尚未完成验证的行为。[现行契约](../interfaces/README_cn.md)描述已实现输入；[验证](verification_cn.md)记录已运行的检查。

## IsOS 门槛

- [ ] 将图准入、Apply、Run 和 Restart 整合为一个有类型的计划，携带所有已验证的归属方、资源、就绪、停止和运行限定。当前包装器与监管器分别保存这些值。
- [ ] 用两个互不相关的合成软件包族测试安装、选项、Apply、Run、Restart、删除和拒绝路径。覆盖畸形或超大元数据、已更改文件、未知资源或归属方、过期修订、就绪失败、不确定停止和关闭。
- [ ] 在启用成功的展示选择前验证归属方描述符注册及端口／类型绑定。当前路由对没有描述符的有效活动输出返回 503。

- [ ] 在已通过的洁净主目录键盘到基座回放基础上，补测浏览器失焦和断线、归属方租约到期、过期运行拒绝及停止失败恢复。已验证的模拟器包通过了按下、续租、释放和确认 Stop；见[验证](verification_cn.md)。

## 外部集成门槛

- [ ] 软件包发布者提供 `isos.package@v1` 贡献，包含注册类型、进程、资源和节点集合。归属方验证自己的负载格式和生命周期适配器。
- [ ] 进程归属方接受绑定的 `isos.package-process@v1` 交接并证明就绪及终止停止。当前 setup、事件和停止通信在归属方迁移前保留各自已记录的模式。
- [ ] 数据归属方注册经过验证的公开描述符，包含精确类型、输出端口、表示形式、负载上限、端点标识、运行 ID 和图修订。
- [ ] IsosUI 使用 `/api/isos/v1/*`，检查 `api_schema_version:"0.1.0"`，并在运行或修订变化时使订阅失效。
- [ ] 归属方迁移后重放安装、选项、Validate、Apply、Run、Restart、展示、日志、Stop 和停止失败恢复。本地桩不能独自证明实时互操作性。
