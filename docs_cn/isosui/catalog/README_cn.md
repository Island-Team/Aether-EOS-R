# 图目录呈现

[English](../../../docs/isosui/catalog/README.md) · [首次使用](../usage_cn.md) · [设计](../design_cn.md)

**U01–U04 所有者功能已合并；跨所有者发布仍未完成。** IsosUI 呈现 IsOS 目录，不注册运行时节点类型，也不拥有负载字段。首次使用按 **core → layer → group → node type** 选择。类型描述说明类型用途；可编辑的实例描述说明本次配置。类型 ID、设置、端口、能力、默认值、单位、校验和兼容规则以所有者 `interfaces/` 契约为准，不在 UI 中复制。

| 层级 | UI 行为 | 所有者及示例 |
| --- | --- | --- |
| Core | 显示就绪、包锁定与状态；不可用时保留原因。 | EOS、EGIA、IsOS 各自拥有实时状态。 |
| Layer | 过滤主要领域，不改变图。 | EOS 硬件、进程、控制；EGIA 智能体阶段；IsOS 管理。 |
| Group | 显示相关注册类型及包来源。 | EOS 相机/底盘/机械臂、MuJoCo 进程、EGIA 感知/上下文/决策。 |
| Node type | 显示目录提供的非空类型描述、位置、设置与类型化端口；仅兼容时允许添加。 | 节点与字段以各核心的接口契约为准。 |
| Node instance | 分别显示可编辑名称/描述、保存设置、错误、运行健康和来源连线。 | IsOS 拥有保存图；EOS/EGIA 拥有运行状态。 |

UI 用精确 `(core, layer, group, type_id)` 查找注册记录，不用翻译后的标签或文件夹名称推导身份。旧侧文件缺少 `NodeType.description` 时，显示服务端兼容描述并标记回退。固定包缺失或无效时，保留图中的 ID、显示原因并阻止应用。兼容的未知字段在草稿中保留；未知未来图版本只读。

节点检查器按 **身份与描述 → 包/版本和可用性 → 设置与选择器 → 端口与连线 → 校验 → 实时状态/日志链接** 排列。选择器保留稳定值，标签与描述只用于呈现。每条连线在应用前显示 nice 优先级和频率上限，包括旧图默认值。日志链接先打开当前运行最初的就绪/故障事件，再按节点路径和关联 ID 过滤。过期修订、选择器刷新和面板持久化算法见[工作台设计](../design_cn.md)。

## 所选目录兼容性

对于已保存的 `0.1.0` 图，Graph 和 EOS 工作台读取 IsOS 的 `GET /node-types/selected` 所选目录，并要求其 `graph_revision` 等于图保存字节的修订。该目录包含归属方准入的 EGIA 阶段及其设置、数据模式元数据。全局 `GET /node-types` 继续用于发现已安装软件包。如果 Apply 与两次读取并发，界面仅重读图和所选目录一次；再次不一致或所选归属方不可用时，原始图保持可见但只读，并禁用 Apply 与 EOS Invoke。未知类型和未来图版本仍保持只读。

EGIA 的正整数和正数设置使用数值编辑器，应用时保留 JSON 数值类型。归属方管理的 `endpoint` 对象按结构化只读值显示，并提示到归属方配置修改；编辑器不会将其转为字符串。运行或重启期间，节点图、首页、EOS 控制和工作区栏均可停止。共享协调器等待已经发出的运行请求结束，再发送最终停止命令，并检查归属方的最终状态；如果期间启动了新运行，停止确认会标明该运行 ID。

如果运行请求仍在进行而首次停止发生传输故障，协调器仍会等待该运行请求并再发送一次最终停止。最终停止失败时，即使运行 ID 改变，工作区停止隔离也会保持，直到显式停止获得确认。对没有待完成运行请求的未知停止结果，界面不会自动重试。

## U01 实现证据（2026-11-02）

编辑器读取注册类型描述与设置元数据，按精确 core/layer/group/type 四元组浏览，并针对每份草稿请求 P03 选项。选择器以精确 `(node_path, setting)` 为键；已保存但不可用的 ID 和所有者原因仍可见。MuJoCo 设备选择在一次编辑中同时更新适配器的两个设备字段。较旧的 POST 响应被丢弃，包括草稿字节不变而软件包改变的情况。注册类型按完整位置四元组匹配，新建 `@v0.1` 节点不填入猜测的硬件值。在当前选项返回且必需或不可用值修复前，保存及保存并运行均禁用；**检查节点图**仍可用，最终 Apply 与 Run 仍由 IsOS 校验。

在本仓库运行 `npm ci`、`npm run typecheck`、`npm test`、`npm run build`、`git diff --check`，以及 `logs/test/20261102-u01-catalog-selector/` 中记录的本地链接检查。完整测试通过（25 个文件、126 个测试），类型检查、本地及托管构建、清单验证和四份文档的本地链接检查均通过。完整输出保存在被忽略的 `logs/test/20261102-u01-catalog-selector/`。最终检查使用 Node.js 22.23.4 和 npm 10.9.9。
