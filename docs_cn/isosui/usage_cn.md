# 首次使用：图与工作台

[English](../../docs/isosui/usage.md) · [设计](design_cn.md) · [TODO](todo_cn.md)

[Q03 验证设计](q03-qualification_cn.md) 固定选定版本的浏览器安装回放和初始界面基线。已发布的 `v0.1.0` 归档与 Island-web 固定版本见[发布记录](interfaces/releases_cn.md)。通过 IsOS 安装已校验的 `local` 发布归档；Island-web 固定 `hosted` 归档。下面的源码构建步骤仍适用于开发。

## 当前路径

1. 安装 Node.js 22 和 npm 10，在本仓库运行 `npm ci` 和 `npm run build`，并在 IsOS 中选择生成的 `dist/local`。也可用 `npm run dev` 在 `127.0.0.1:16001` 启动独立前端；图编辑和实时控制仍需要 IsOS、EOS 回环 API。
2. 运行 `isos serve`，打开 `/en/isos` 或 `/cn/isos`。Home 显示管理器设置、已安装包收据、核心就绪状态、进程状态与全部来源日志。API 离线应显示阻塞原因，而非空图。
3. 在 IsOS 中安装或链接精确的 `island/mujoco-sim@0.1.1`。在 Graph 选择 `sim-hardware` 节点集，预览新增节点并选择场景。在 Graph 中按 **core → layer → group → node type** 浏览。通过 `/node-options` 中 `eos/process/mujoco/simulator` 的可搜索选项选择场景，再按各相机／底盘／机械臂的精确 `node_path` 选择设备。一次设备选择同时写入 `adapter.settings.device_id` 和 `adapter.settings.simulator_node`。
4. 选中节点，分别阅读注册类型描述和可编辑的实例描述，并配置类型声明的字段。搜索所有者提供的选项名称与说明，查看已保存但不可用的 ID 及修复原因。更改场景或软件包后，等待当前草稿的设备选项刷新，再尝试应用；连接兼容的输出和输入端口，然后在“高级操作”中选择 **Check graph**。若连线高亮，选中它：检查器显示来源/目标类型 ID、IDL 字段单位，以及该输入端口的 IsOS 拒绝代码、路径和原因。“诊断”区域保留完整服务器结果。修正端口或节点设置后再次检查；修改草稿会使上次检查结果过期。检查器里的部署状态与节点实时健康分开，后者可在 EOS 监视器查看。确认检查通过后，再用 Graph 主操作保存并运行修订。由服务器验证、应用图；浏览器草稿本身不能控制 EOS。
5. 等待 Home 显示就绪，再打开 EOS 控制与监视。只有活动图声明的节点才显示控制。工作区工具栏可分别打开控制、监视、Vision 和日志面板；Graph 的 View 菜单打开同一个持久 EOS 控制面板。EGIA 仍使用 Graph 核心窗口。

6. 若启动前失败，打开 Home Logs。固定的管理器会话锚点显示首条软件包或 Apply 故障，即使详情筛选隐藏了该来源。启动后，面板固定本次运行的首条就绪或故障事件。可按来源、级别、节点路径或关联 ID 筛选后续详情行，锚点仍可见。将运行 ID 和关联 ID 用于 EOS／EGIA 排查。实时就绪及保存／活动修订以 Home 状态为准；活动修订过期会阻止实时控制。
7. 通过 IsOS 停止部署。升级时安装精确的新包版本，预览节点、检查图、应用新修订并重启；保留旧图和包收据以便恢复。

若归属方目录读取较慢，等待 EOS 控件当前刷新完成；五秒后台定时器不会取消正在进行的读取。点击工作台 **刷新** 可请求新的归属方快照；在新的已保存节点图、所选目录、进程状态和 EOS 发现结果一致前，Invoke 保持禁用。所选目录不可用或修订不匹配时，控件保持只读并显示原因。

仓库根目录 [README](../../ui/README_cn.md) 记录已实现的开发命令、API 来源和构建输出。包安装和进程操作由 IsOS 负责。

## P07 日志导航

包或 Apply 失败后打开 Home 日志。面板向 IsOS 请求 `view=current`，在来源、级别、节点和关联筛选器上方显示管理器会话中的首条包／Apply 故障。尚未收到该事件时显示锚点待定；空列表不表示成功。IsOS 准入部署运行后，面板切换到该运行的首条就绪或故障事件，再显示后续详情行。停止、进程退出或管理器重启后仍选择该运行，直至 IsOS 准入下一次运行。实时就绪及保存／活动修订以 Home 状态为准；日志只解释其发生时的事情。

暂停 Follow 后查看行内安全的来源、核心、事件代码、运行 ID、关联 ID 和图节点指针。先看固定首事件，再筛选详情行。保留策略或轮转造成丢失时，面板显示缺口通知并在同一运行内继续；收集器不可用时保留末次行和游标，并持续显示错误直至恢复。新准入运行显示可见边界及自己的锚点。浏览器控制台诊断与 IsOS 事件分开。P07 面板显示归属方报告的事件身份；IsOS 不支持显式响应时保留旧版兼容视图。详见 [P07 UI 契约](interfaces/log-cursors_cn.md)。

筛选后空页若游标推进且无诊断，仅表示暂时没有匹配详情行，不是缺口。状态报告 `run_id_state:unavailable` 或当前日志返回 `log_scope_unavailable` 时，将旧行标为过期，身份恢复期间以实时状态为准。Run 返回 `log_scope_publish_failed` 表示没有子进程启动，但持久运行记录可能仍幸存；解释范围前须刷新状态与当前日志。这两种情况都不允许 UI 自行选择管理器会话或宣称就绪。

[R07 浏览器原语客户端](interfaces/browser-results_cn.md)已合并，并验证一个受管理 `mock-cxx` 底盘绑定。[共享 R07 记录](https://github.com/Island-Team/Island-eos/blob/master/docs_cn/island/implementation-todo_cn.md)记录了一次操作员点击：同一命令 ID 经历 `Sending`、`InProgress` 和持久化 `OutcomeUnknown`；同运行已确认 Stop 及结果围栏也通过。这是限定于模拟底盘的首次使用；R07 重放范围限于模拟底盘；U04 现已提供逐绑定控件，后续获批准的发布资产 run-7 已完成既定范围的 M5 发布重放。其最小 EOS 卡选择一个合格的活动 `base.velocity` 绑定，显示图解析的 base 目标及有界 `body_velocity` 字段，只在操作员点击 Invoke 后发送 `primitive_typed`。受管理模拟重放验证了这条路径；真实 MuJoCo 运动仍由 R06 把关。记录 IsOS 运行 ID 和相等的保存／活动修订，取得 EOS 单调时间，浏览器本地 `sending` 期间持续显示生成的命令 ID。EOS 返回 `InProgress` 时，只有 IsOS 仍报告同一运行中的部署，才用该 ID 和修订读取有界公开 `result` 操作。精确显示 `Completed`、`Failed`、`Cancelled`、`Rejected`、`InProgress` 或 `OutcomeUnknown`；桥接离线、旧运行或修订过期都显示不可用，绝不当成成功。发送超时后不重发命令。打开无筛选的 Home 当前运行日志；只有 EOS 所有者事件提供与命令对应的有效关联 ID，才能预填关联筛选。命令 ID 单独显示。即使 EOS 离线，IsOS 部署 Stop 仍须可用。逐绑定控件和图信息卡见下文。U03 提供持久工作区面板。

### 使用受管理模拟底盘首次运行 R07

在 IsOS 中应用一个包含 `base.velocity` 原语绑定及唯一 `mock-cxx` 底盘目标的图，然后运行。打开 EOS，等待底盘状态及健康就绪。核对卡片显示的绑定和目标路径及 SI 限值，输入有界速度和有效期，再点击一次**调用**。卡片保留命令 ID，显示 EOS 精确状态，且只有 IsOS 确认同一运行和修订时才跟进 `InProgress`。自动读取暂停后可点击**刷新结果**。通过 IsOS 点击**停止部署**，再打开**当前运行日志**。日志视图不以命令 ID 预设筛选；命令 ID 留在卡片上供比对。

受管理模拟重放的首个命令返回 `OutcomeUnknown`；Stop 并重启后，卡片必须保留该所有者状态和 ID，同时显示**不适用于本次运行**。新运行中再次由操作员点击后，EOS 返回 `Rejected`，因为不确定的释放使运动仍被禁止。检查新命令的结果和当前运行日志；不要重发旧运动，也不要把模拟 Stop 响应当作 MuJoCo 物理停止证明。EOS 检出目录中被忽略的 `logs/test/20261102-r07-cross-owner-live/SUMMARY.md` 记录了精确图、修订、响应体和命令。

点击**停止部署**后，在 IsOS 响应前显示**正在停止…**。Stop 提示与实时状态分别检查：**停止已确认**需要相同运行 ID 和 `terminal.outcome:"confirmed"`；**停止结果未知**包含固定原因代码，应查看当前运行日志。**停止未获确认**表示终态响应缺失、为 null、损坏或属于另一运行。若从未运行且 `run_id_state:none`，显示没有需要停止的受管运行。**停止响应不可用**表示未收到响应；再次操作前检查更新的 IsOS 状态和日志。状态刷新失败不改变显示的 Stop 结果。点击后旧 EOS 命令结果保持隔离，包括迟到响应。

若 IsOS 明确拒绝 Stop，告警显示**IsOS 拒绝停止**及所有者消息。即使子进程已回收，`terminal:null` 仍是未确认；重复的子进程结果不能确认 Stop。

U01–U04 已合并到 IsosUI `master`（见[所有者状态](todo_cn.md)）。以下步骤描述已实现的界面。[历史 M4 受影响边界回放](https://github.com/Island-Team/Island-eos/blob/master/docs_cn/island/m4-affected-replay_cn.md)验证了受监管任务和独立的浏览器命令，但未验证同一次运行内替换 EGIA 子进程。后续 [Q03 final-17 与 Q04 final-5 回放](q03-evidence_cn.md)各自固定输入。IsosUI 标签与托管归档已发布，并由 Island-web 固定；后续[已批准的发布资产 run-7](https://github.com/Island-Team/Island-eos/blob/master/docs_cn/island/q04-merged-qualification_cn.md)已完成既定范围的跨所有者发布重放；公网 HTTPS 首次使用仍待验证。

对于已保存的 `0.1.0` 图，编辑或调用 EOS 前先等待所选归属方目录，并核对 `graph_revision` 与保存修订一致。全局目录列出可安装的软件包类型；所选目录提供这张图的 EGIA 阶段及设置。归属方目录不可用，或读取时修订连续两次变化时，先以只读方式检查原始图，待归属方恢复后重试。参见[目录契约](catalog/README_cn.md)。

Graph 首先显示可搜索的注册类型库。选中类型时显示非空的**类型描述**、层级位置、能力、端口契约和设置帮助；选中实例时显示可编辑的实例描述。配置表单按目录元数据生成。选择器按**节点与设置**搜索已验证的选项；此处支持场景和设备。模型权重资源只是扩展点，本次不执行 EGIA tensor。选择器标题显示精确包和版本锁定；每项显示稳定 ID、名称、描述、可用状态与原因。已保存但不可用的值保持可见并解释原因，不能静默替换；Check graph 仍可用并报告未解析或无效选项；修正前阻止 Apply。包路径留在 IsOS 内部，图只保存稳定 ID 和精确包版本。

鼠标在节点上停留约半秒后，在指针旁显示浮动信息卡；键盘聚焦或点击信息按钮可立即打开。点击或拖动节点时，该节点位于相邻节点之上。分别显示注册类型描述与实例描述，以及层级、端口和单位；仅在所属核心报告时显示实时健康。将卡片限制在视口内，提供触摸入口，同时不妨碍拖动节点和编辑连线。

每条连接可编辑 `priority`（nice 值 `-20..19`，默认 `0`）及可选 `frequency_hz`（有限正数，表示传输频率上限）。检查器根据 IsOS 验证结果编辑。正常缩放和键盘焦点提示都显示两个值；图例将优先级、频率与传输方式、负载类型分别解释。尚无运行时路由的边明确标为**仅设计**。优先级只影响调度，不绕过 Dispatcher 安全准入。

工作区让**控制**、**监视**、**Vision**、**日志**面板分别停靠或浮动。浮动面板有拖动、调整大小、焦点顺序、关闭/停靠操作、有界视口和本地布局保存；恢复时把几何位置限制在当前视口。窄屏按顺序叠放，保留 Stop 操作和重要的连接或修订警告。普通消息短暂显示，并留在日志的浏览器分区。工作页面采用紧凑对齐的行、透明或轻微半透明背景；视觉概览页面可用更宽的间距。两类页面共享参考 Island-web 的样式 token、克制的边框、可见键盘焦点、28–30 px 桌面控件和至少 44×44 px 触摸目标。

完整 U04 原语演示按以下顺序使用：查看节点，检查并应用图，等待 EOS 就绪。在 EOS 控制面板中选择一个活动原语绑定并查看从图解析出的唯一目标；要改变目标须编辑图并 Apply。面板显示两种节点描述，并按所属契约显示类型化原语字段。通过现有回环 `primitive_typed` 桥接调用。先显示浏览器本地的发送状态，再根据关联响应显示精确的 `Completed`、`Failed`、`Cancelled`、`Rejected`、`InProgress` 或 `OutcomeUnknown`；`InProgress` 在经授权结果读取确认前保持未完成。当前运行日志与实时健康分别呈现；仅当 EOS 所有者事件提供对应的有效 ID 时按关联筛选日志。图上的连线本身不表示命令已经执行。通过 IsOS 停止。[Q03/Q04 回放记录](q03-evidence_cn.md)已记录选定洁净主目录和合并后提交的路径；后续[已批准的发布资产 run-7](https://github.com/Island-Team/Island-eos/blob/master/docs_cn/island/q04-merged-qualification_cn.md)已完成既定范围的 Q04/M5 发布关卡。

### 连线服务质量检查器

选择连线后点击**检查节点图**。检查器依据 IsOS 返回的精确来源指针显示路由类别。仅当 IsOS 确认连线已声明路由、允许 QoS 且不是固定连线时，才能编辑优先级和频率上限。nice 优先级为 -20（最高）至 19（最低）的整数，有效权重为 `20 − 优先级`；频率上限留空表示无限制。生产者预期频率仅是单独提示。输入后按 Enter 或离开字段提交草稿。每次编辑都会清除先前的路由授权；再次编辑 QoS 前需重新**检查节点图**。无效值阻止保存和保存并运行。Apply 前会重新请求 IsOS 检查精确草稿；拒绝或过期检查不会发送 Apply。仅设计用途与固定连线仍可查看，但不能编辑 QoS。

## U04 节点卡与原语控制

鼠标在 Graph 节点上稍作停留、键盘聚焦或轻触信息按钮，即可查看独立的目录类型与实例描述、类型化端口以及 EOS 所有者报告的健康状态。Escape 或关闭按钮退出视口内的信息卡。在 EOS 中，每个受支持的活动 `@v0.1` 底盘或机械臂绑定都有独立控制卡。检查图解析的唯一目标、原语、单位和限值；更改目标须编辑并 Apply 节点图。等待已知 IsOS 运行、相等的保存／活动修订及 EOS 就绪健康状态。仅点击一次调用。浏览器显示发送中时保留命令 ID，随后显示 EOS 的精确状态。`InProgress` 仅用同一 ID 经授权的公开结果读取跟进；丢失响应绝不重新提交。EOS 控制失败时仍可通过 IsOS 停止部署。参见 [U04 契约](interfaces/primitive-control_cn.md)。

## U03 首次使用：工作区面板

打开节点图，通过工作区工具栏分别显示控制、监控、视觉和日志面板。每个面板都可以停靠、浮动、收起或关闭。拖动浮动面板标题可以移动；聚焦右下角手柄后可用方向键调整大小。窄屏时面板堆叠显示。紧凑的顶部导航始终提供“停止部署”；仅在重要警告或停止请求待确认时显示第二条顶部提示。普通消息五秒后消失，并留在日志的浏览器分区。即使 EOS 离线，也可以通过 IsOS 请求停止。

在控制面板调用原语后，切换页面、停靠或收起面板时，命令 ID 与所有者结果仍保留。点击“停止部署”会立即阻止本次运行的新调用和结果跟踪；停止结果不明时，界面不会显示为停止成功。关闭或收起监控与视觉面板会暂停轮询或视频流。日志面板停靠或收起时保留本次运行的不透明游标并暂停跟踪；关闭后重新打开会重新检查 IsOS 状态与日志范围。布局按机器人保存在本机，并限制在当前视口内。参见[工作面板契约](interfaces/workspace-panels_cn.md)。选定的 Q03 R06/A03 恢复与合并后 Q04 final-5 回放分别在各自固定输入上通过；后续[已批准的发布资产 run-7](https://github.com/Island-Team/Island-eos/blob/master/docs_cn/island/q04-merged-qualification_cn.md)已完成既定范围的跨所有者发布回放。

查看所选 Vision 证据时，先等待 Home 报告当前运行就绪，再打开 Vision 面板。面板使用 IsOS 选择的 gate 与来源，订阅 EOS 公共 bridge，并显示运行、gate 代次、stream、JPEG 摘要、实际帧率和本地观察到的跳过代次。“尚无新画面”表示已证明的流就绪但尚未交付图像；“画面被拒绝”说明本地来源或摘要校验失败。停止、运行或修订变化、隐藏面板都会移除图像。参见 [Vision 来源契约](interfaces/vision-provenance_cn.md)。选定的 Q03 相机和合并后 Q04 final-5 Vision 回放均已通过；final-5 在回环地址模拟托管 Origin。
## 节点图加载

所选节点图与目录快照的修订一致后，节点图可以先显示；进程状态、就绪状态或软件包节点集仍可能在加载。点击**重新载入已保存节点图**会请求新快照；响应通过修订检查之前，原画布继续显示。首页每五秒只轮询进程状态；外部修改软件包或节点图后，点击**刷新**以重新加载完整的所有者视图。参见[节点图加载契约](interfaces/graph-loading_cn.md)。

## Q03 验证回放

用 Node 22／npm 10 构建选定的 IsosUI 源码，并核对两个 manifest 的源码提交。通过 IsOS 提供 `dist/local` 执行操作流程；托管路径则把 `/en/isos` 和 `/cn/isos` 映射到 `dist/hosted/index.html`。在全新 IsOS 主目录中安装已验证的仿真器包，选择场景和设备，执行 Validate 与 Apply，然后确认保存和活动修订相同、所有者已就绪。检查 Graph 中的类型／实例描述和连线诊断，分别打开控制、监控、视觉和日志面板。仅在 EOS 报告目标健康时调用一次活动原语绑定，按命令 ID 跟踪终态结果和本次运行日志，再注入故障／重启并确认运动未被重放。通过 IsOS 停止并检查已确认或未知的终态。最后测试显式迁移与不支持节点图的只读路径。[Q03 证据记录](q03-evidence_cn.md)记录封存的 final-17 选定回放及另行固定输入的 Q04 final-5 合并后回放。两者都在回环地址模拟托管 Origin，不能证明真实公网 HTTPS 首次使用。后续 IsosUI 标签发布与网站部署见发布记录。
