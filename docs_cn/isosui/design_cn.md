# 编辑器与可停靠工作区设计

[English](../../docs/isosui/design.md) · [首次使用](usage_cn.md) · [TODO](todo_cn.md)

**目标：** IsosUI `0.1.0` 配合 IsOS `0.1.0` 和 EOS `0.2.0`。当前编辑器支持 `0.1.0` 图和已注册 `@v0.1` 类型，并安全读取旧版 `1.0.0` 图、类型专用表单、节点集预览、由已配置连线上限推导的频率线型、独立的 EOS 控制／监视／Vision／日志面板、EGIA 核心窗口，以及下述连线检查器。下文标为**目标**的能力仍需实现。产品版本、图版本、节点 ID、HTTP 路由与模拟器套接字版本分别管理。

## 所有权与数据流

IsOS 拥有已保存图、类型目录、包收据、`/api/isos/v1/node-options`、验证、修订、Apply、管理器状态与统一日志游标。EOS 拥有实时适配器状态、观察、控制与准入。EGIA 拥有代理阶段状态。IsosUI 只保存图草稿、服务器修订、临时选项结果和浏览器本地面板布局。不能从草稿推断已验证包路径、命令权限或实时状态。所有者契约见 IsOS 的 `interfaces/node-graph.md`、`interfaces/releases.md` 和 EOS 的 `interfaces/hardware.md`、`interfaces/control.md`；本页只定义 UI 呈现。[节点图加载契约](interfaces/graph-loading_cn.md)规定快照与后台状态请求的顺序。

目标 UI 状态为 `{saved_revision, draft, validation, active_revision, catalog, options, readiness, panels}`。编辑更新草稿并使验证结果过期。`Check graph` 请求 IsOS 验证但不写入。`Apply` 发送精确的已保存修订与草稿；冲突时保留本地草稿并展示服务器修订，让操作员明确协调。编辑器保留未编辑的附加字段，不会仅因显示节点图就改写已存字节。IsOS 图响应新增的 `read_only` 和 `diagnostics` 字段为准：只读时禁用编辑、验证、Apply、场景更改、节点集预览、Run、Restart 和 EOS 控制提交，但仍可检查、刷新、查看日志和紧急 Stop。旧版 IsOS 未返回 `read_only` 时，未知图版本或目录中缺少的节点类型也强制只读，并显示版本或类型诊断。保存图的修订与 EOS 活动修订不一致时，不能把它当作活动控制绑定。UI 版本 `0.1.0` 不代表图 `1.0.0` 已稳定。

## 类型驱动配置与选择器

注册类型提供位置、非空描述、字段与有类型端口；实例提供 ID、标签、描述、设置、包锁定和输入引用。旧包侧车若缺少 `description`，使用 IsOS 的兼容默认，并在 UI 标记为目录默认，而非编造设备描述。每个可见字段从所属契约取得标签、类型、适用单位、用途、默认值与验证帮助；必填空值和单位错误就地显示。

**目标节点信息卡。** 鼠标悬停和键盘焦点打开同一个悬停时位于指针旁、键盘聚焦时位于节点旁的非模态小卡片。它分别展示标签、类型 ID、注册类型描述与实例描述、声明端口的类型/单位帮助，以及仅在 EOS 报告活动节点状态时显示实时状态。卡片通过画布 portal 浮于其他节点上方，限制在视口内，不遮挡拖动起点或连线手柄；指针进入卡片后可继续阅读。仅在用户请求时将焦点移入内容，Escape 关闭；触屏用户可从节点信息按钮打开。缺失的旧类型描述标为兼容回退；不能为草稿节点编造实时健康。

目标设置元数据中的 selector 描述符指定 IsOS 选项来源；本次每项设置只选择一个稳定值。`POST /node-options` 接收当前草稿，响应按节点路径和设置名分组。每个选项包含稳定值、标签、描述、可用性和不可用原因。UI 可按标签、稳定值、描述搜索，支持方向键、Enter、Escape、输入搜索和屏幕阅读器结果数。图只保存稳定 ID，显示标签不进入图。包锁定、依赖设置或图草稿变化时重查；以请求代数忽略过期响应。已选 ID 消失或不可用时，表单保持它并显示警告，阻止 Apply 直到选择有效项。首批选择器是 MuJoCo 场景和设备；同机制以后可支持模型权重等包资源。任意文件路径输入不能代替经过验证的注册选项。

## 连接呈现与编辑

**已实现的连线检查器。** 当前 Graph 检查器比较来源和目标端口声明的精确类型 ID，并显示两侧 IDL，包括负载字段的 `x-unit` 单位标注。缺少目录描述符时显示元数据不可用，不将连线误标为已拒绝。执行 `Check graph` 后，编辑器把四段连线目标路径映射到 IsOS 展开的诊断指针，只把 `/inputs/<port>/<source-index>` 诊断附在对应连线上，显示代码、路径和消息；多来源输入的端口级诊断保留在完整“诊断”区域。被拒绝的连线有可见线条与无障碍文本。修改、撤销、重做或刷新草稿会清除此验证结果及路由授权，再次编辑 QoS 须先检查节点图，旧编辑请求的迟到响应会被忽略。检查器将其标为**草稿检查**，另行显示 IsOS 部署状态，并可打开 EOS 监视器查看节点实时健康；Graph 连线本身尚未显示单节点实时健康标记。连线兼容性以精确类型身份为准，UI 不转换负载单位。检查器依据 IsOS `Validate.edges` 的精确来源指针，仅为 `routed:true`、`qos_eligible:true` 且 `fixed:false` 的连线提供优先级和频率上限编辑。通用资源选择器仍待实现；U03 已提供独立的控制／监视／Vision／日志面板。

边是输入上的来源引用。目标可选 `priority` 为 `-20`（最高）到 `19`（最低）的整数，默认 `0`；可选 `frequency_hz` 是有限正数，缺失表示该边无上限。生产者端口的 `expected_rate_hz` 仍只是提示，不是保存的边限频。优先显示实际配置；无边限频时显示 `unlimited`，生产者提示可单独显示。旧来源引用显示优先级 `0`、无限频，但不修改图。只编辑选中的边，保留未知的兼容字段，本地验证即时反馈，Apply 前由 IsOS 再验证。

传输锚点形状、精确负载类型颜色、节点层/组标记、运行故障轮廓、边优先级/频率指示分别编码。目标线型表达配置的限频；实线表示无限频，而非测得高频。线路、检查器和无障碍名称都显示如 `nice 0 · ≤ 20 Hz` 的文本。优先级使用不依赖颜色的标记或线宽等级，提供图例和焦点/悬停详情。线型依据保存的连线上限；生产者 `expected_rate_hz` 仅为单独提示。优先级用不依赖颜色的线宽呈现，无障碍标签包含 nice 与上限。尚未确认运行时路由的边显示“仅设计”，不暗示已实际传输。

## 原语控制——已实现

**当前原语控制。** EOS 控制面板对活动图中的每个 `eos.dispatcher.primitive_base` 或 `eos.dispatcher.primitive_manipulator` 绑定单独列出一项，即使原语名称相同。选中后显示绑定的类型/实例描述、从活动图解析出的唯一目标、声明的原语/版本/模式、参数单位/边界，以及 EOS 报告的目标健康。活动修订过期、目标缺失或不唯一、EOS 不可用、参数无效或目标不健康时禁用 Invoke。面板取得 EOS 单调时钟时间，构造现有 `primitive_typed` 命令头/载荷，经 `/api/eos/v2/control` 提交；EOS 检查活动绑定，由 Dispatcher 准入物理动作。调用后选中的 Graph 节点显示 `sending`，再显示精确关联的 `Completed`、`Failed`、`Cancelled`、`Rejected`、`InProgress` 或 `OutcomeUnknown`。`InProgress` 保持非终态；后续结果需要经授权的 bridge 结果读取。视觉脉冲取自关联响应或运行事件，不把仅设计连线或浏览器猜测当作成功。面板保持 IsOS Stop 与命令 ID 可见。[R07 客户端设计](design-browser-results_cn.md)定义运行／修订围栏、类型化后续查询及不可用状态；完整原语表单已在 U04 实现。EGIA 的 gRPC CapabilityService 是汇入同一 Dispatcher 的独立入口，不是浏览器 API。

R07 验证首先通过模拟适配器证明一个操作员点击触发的活动 `base.velocity` 绑定、有界 `body_velocity` 表单、类型化发送、`InProgress` 后续查询及 IsOS Stop；真实 MuJoCo 运动须等 R06 停止验证后才开放。U04 已为每个受支持的活动 base 和 arm 绑定提供独立控件和图节点信息卡；见 [U04 设计](design-primitive-control_cn.md)。

## 面板与页面类型

Home、Graph、配置属于**工作页面**：紧凑对齐、方便扫读、有界滚动、状态上下文持续可见。概览或解释性首页属于**视觉页面**，可用更宽间距和图像。两类页面共享现有 SCSS 主题 token、Island-web 的排版参考、透明或轻微半透明表面；实色填充只用于提高可读性。桌面控件约 28–30 px，触控目标至少 44×44 px。全部控件有可见键盘焦点、禁用与错误状态；状态不能只靠颜色表达。

已实现的 U03 工作区面板（`control`、`monitor`、`vision`、`logs`）各自在浏览器本地存储 `{open, docked, collapsed, x, y, width, height}`，以布局版本和机器人 ID 为键。拖动/调整大小只改几何信息。按机器人和布局版本保存在本机；加载时拒绝损坏数据、限制在视口内并恢复安全默认布局。停靠不销毁面板内容和订阅。关闭 Vision 断开流，隐藏日志 Follow 暂停轮询，监视轮询有界且不活动时停止。活动修订过期或 API 失联时禁用命令，即使面板重叠也保持错误可见。焦点按最近活动面板排列；Esc 取消拖动/调整大小而不改图。窄屏强制按顺序叠放，保留关键状态和 Stop 控件。

## 首次使用的可观测性算法

打开 Home 时获取 IsOS 状态作为实时就绪依据，并从可选的 `view=current` 日志范围读取历史。任何运行准入前固定显示管理器会话的首条包／Apply 故障；启动后在详情筛选前固定显示持久保留的部署运行首条就绪或故障。锚点待定时显示等待且不展示详情行。停止、PID 消失、活动修订清空及管理器重启不替换末次运行范围。IsOS 提供时，日志行呈现时间、级别、来源、核心、可选 `node_path`、`event_code`、`run_id`、可选 `correlation_id` 和消息。浏览器错误与服务端来源分开显示。游标轮询依据 IsOS 的同运行重定位诊断继续，显示轮转缺口及新运行边界，绝不拼接不相关的运行。[P07 日志设计](design-log-cursors_cn.md)定义具体状态机；首次使用指南按包→图→Apply→就绪→控制→日志→停止的顺序教学。

## M1 读取兼容性验证

2026-11-01 在 IsosUI 仓库使用 Node 22.23.4 和 npm 10.9.9 运行 `npm test`，17 个文件中的 62 项测试全部通过；`npm run build` 通过 TypeScript 检查、本地和托管生产构建以及产物验证。完整输出保存在 `logs/test/20261101-g05-reader-compat/test.log` 和 `build.log`。新增测试覆盖服务端只读提示、未知版本及类型、目录不可用和附加节点图字段保留。UI 仍依赖 IsOS 拒绝不安全的 Apply 请求；这里的控件防止不受支持的节点图提供本地编辑和启动操作。

**U02 连线检查器（2026-11-02）。** UI 仅使用 IsOS `Validate.edges` 中与输入对象或数组索引精确匹配的来源指针判断路由状态。只有 `routed:true`、`qos_eligible:true` 且 `fixed:false` 的连线可编辑 nice 优先级（-20..19）与有限正数 Hz 上限；其他连线标为“仅设计用途”或固定安全连线。旧值缺失时显示 nice 0、无限制而不写入字段；清空上限会删除字段。保留来源对象／数组结构、同级来源与未知字段。线型读取保存的上限，生产者 `expected_rate_hz` 仅作单独提示；优先级由独立线宽表示。编辑后当前验证失效，保存前重新请求 IsOS Validate；拒绝或过期响应不发送 Apply。诊断按精确来源指针附着，实时健康仍独立显示。

**U02 本地证据（2026-11-02）。** 在基于 IsosUI master `5d39968` 的 U02 分支 `refactor(v2)/ui-edge-qos-inspector`（初始提交 `cd7bd8b`），使用 Node 22.23.4、npm 10.9.9，`npm test` 的 28 个文件共 135 项测试通过，`npm run typecheck` 通过，`npm run build` 生成有效的本地与托管产物，`git diff --check` 通过。完整输出及精确运行时路径保存在被忽略的 `logs/test/20261102-u02-edge-qos/SUMMARY.md`。M4 所有者实时首次使用重放另行执行。

**U03 实现边界。** `App` 在 Graph 和 EOS 页面之间只挂载一个 `EosWorkbench`，并持有全运行 Stop 意图引用。固定区域从 IsOS 显示连接状态与活动修订，并直接调用 IsOS Stop；发出请求前同步写入 Stop 意图。`PrimitiveBaseCard` 观察同一围栏，终止本次运行的结果跟踪，不把未知 Stop 当成成功。四个工作区面板共用按机器人和版本存储的布局以及有界焦点顺序。隐藏控制面板保留命令记录并暂停自动轮询；隐藏监控与视觉时停止轮询或套接字。单个日志面板在停靠和收起时保留不透明游标；关闭后重新打开则重新检查 P07 状态和范围。`GraphCoreWindow` 只保留给 EGIA。U03 不宣称已通过 A03 最终恢复事件回放。
