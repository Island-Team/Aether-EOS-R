# EI（Embodied Intelligence）

[English](../../docs/ei/README.md) · [文档首页](../README_cn.md)

EI 是 IsOS 单一图核心中的认知与安全领域。它在独立进程中运行，通过显式的所属接口与 EOS 通信。原 EGIA 命令和导入名作为已发布输入的 0.2.1 兼容别名保留。

先阅读[名称迁移](ei-transition.md)、[接口](interfaces/pipeline.md)、[设计](design/architecture.md)、[开发](develop/build-and-run.md)。源码位于 [`ei`](../../ei/)。
