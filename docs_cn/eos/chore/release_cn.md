# 1.0.0 发布验证

[English](../../../docs/eos/chore/release.md)

公开候选版本在 `etc/eos/eos.example.toml` 中选择无需硬件的 `demo` profile。站点绑定和厂商适配器由部署方维护。本页记录验证证据；未测试的构建不能视为硬件支持证明。

## 1.0.0 变更

- 这是 EOS 首次公开的源码快照。私有部署适配器、站点 profile 和站点 workflow 不进入公开历史；通用 ALSA、aplay 和 V4L2 后端保留。
- 产品、内置技能和后端描述版本统一为 `1.0.0`。`observe_human@1.0.0` 使用较新的躺卧人员选择行为；原有行为保留为 `observe_human_legacy@1.0.0`。
- 人员交互技能现在需要部署侧提供路点 ID 和机械臂姿态；`observe_human` 需要显式提供云台重新定位角度。升级后的调用方须传入这些参数。
- demo 配置使用回环设备。人脸和语音模型端点只是示例，不随仓库提供模型服务。
