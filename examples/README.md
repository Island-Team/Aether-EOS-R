# Examples

These tracked teaching samples are not installed as EOS runtime resources.

- [`packages/hello/`](packages/hello/README.md) demonstrates a small Island package release.
- [`skills/local-native/`](skills/local-native/) is a scaffold for a checkout-local native skill registration.
- [`workflows/hello.json.example`](workflows/hello.json.example) is a workflow template to copy into `share/eos/workflows/`.

See the [local deployment guide](../docs/eos/usage/configure.md) before using an example with a robot.
