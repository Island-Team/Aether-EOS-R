# EOS 0.x implementation TODO

The [detailed Island implementation TODO](docs/island/implementation-todo.md) is the
canonical, dependency-ordered plan for EOS 0.2.0 and the first MuJoCo-backed
IsOS, EGIA, and IsosUI release. Start with the [milestones](docs/island/implementation-milestones.md),
then follow the owned contracts and acceptance evidence linked from each task.

The former root backlog mixed current Rust work with future model, Python skill,
shared-memory, ROS 2, multi-OS, and old C++ runtime proposals. Bounded graph,
package-log, dispatcher, skill-admission, and UI ideas are now tracked in G04/G06,
P01/P06/P07, R03/R04, and U02. The other proposals are outside the 0.x target;
the M5 last-caller audit owns legacy C++ removal. No Workflow or ActionList
execution is part of this target.
