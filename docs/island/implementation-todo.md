## Minimum integration matrix

| Route | Required positive and negative assertion |
| --- | --- |
| IsOS graph → EOS/EGIA config | New and legacy fixtures start when supported; unknown type, stale revision, bad package or missing feature fails before child launch. |
| EOS camera → gate → Vision/EGIA | Typed frame provenance and bounded delivery; stale frame, rate cap and queue overflow are visible without fabricated evidence. |
| EGIA mission → safety → EOS → MuJoCo | One admitted command and correlated terminal result; bypass, duplicate conflict, timeout and unknown outcome fail closed. |
| IsosUI → IsOS Apply and EOS control | Unavailable selection and stale revision block Apply; control reaches EOS admission only for active declared nodes. |
| All cores → IsOS logs → IsosUI | Startup/ready or first failure is found before filters; redaction, rotation and cursor restart preserve run boundaries. |
| Stop/restart | EOS actuator stop precedes simulator termination; EGIA rediscovery precedes new action; IsOS reports forced/unknown outcomes explicitly. |
