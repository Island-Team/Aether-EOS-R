# EI (Embodied Intelligence)

[中文](../../docs_cn/ei/README_cn.md) · [Documentation home](../README.md)

EI is the cognition and safety domain of the single IsOS graph core. It runs as a separate process and communicates with EOS through explicit owner interfaces. The former EGIA command and import names remain compatibility aliases for published inputs through 0.2.1.

Start with the [transition guide](ei-transition.md), [interfaces](interfaces/pipeline.md), [design](design/architecture.md), [development](develop/build-and-run.md). The source project is in [`ei`](../../ei/).
