# Maintain IsOS

This folder is for maintainers checking the current implementation and its integration boundaries. It is an evidence index, not another public contract; external fields are defined in [interfaces](../interfaces/README.md).

- [Verification](verification.md) lists reproducible formatting, lint, test, fixture, documentation parity, and source-audit commands with the latest recorded results and log location.
- [TODO](todo.md) tracks remaining implementation work and external owner, package, and IsosUI gates so a partial path is not described as proven live interoperability.
