# Configure IsOS

This page is for operators choosing local or production settings. IsOS reads the selected TOML file first, then fills missing fields from the complete defaults in [`config/isos.example.toml`](../../../crates/isos/config/isos.example.toml). TOML `#` comments are notes and never become settings. The default selected file is [`config/isos.toml`](../../../crates/isos/config/isos.toml); `ISOS_CONFIG` selects another file by absolute path. The selected file may contain only the values you need to change.

The source priority is `.env`, [`.env.example`](../../../crates/isos/.env.example), the selected TOML, then its example defaults. The source launchers load `.env` first and fill missing environment values from `.env.example`; those values override TOML. For an installed binary, an already set process environment value takes priority, followed by owner-only `~/.config/isos/active.env`, selected TOML, and example defaults. The installed binary does not load either source-launcher file. A relative path in TOML resolves from the IsOS checkout. Use absolute paths in `active.env`, which the installer creates with mode `0600` when `--activate-env` is supplied. This activation file is for IsOS home, ports, and owner locations; it does not contain package-specific settings. Production installations use the same defaults automatically and keep local overrides in their selected TOML. The installer creates a comment-only override file when none exists.

To change a port, add `[server]` and `http_port = 16000` or `ui_port = 16001` to the selected TOML. Both values are integer TCP ports from 1024 through 65535. To change a core binary directory, add `[paths]` and the corresponding `aether_bin_dir` or `egia_bin_dir` path; the example lists all accepted settings, units, and defaults. Do not copy example comments into an environment file as settings.

If a verified package declares a required host input, add `[package_host_inputs]` to the selected TOML and set its declared environment name to an absolute host path. Each key is an uppercase identifier of at most 64 characters; `ISOS_`, `ISLAND_`, and `EGIA_` keys are reserved. The default map is empty. IsOS passes only a package-declared input to its owner, and the owner checks the path's meaning and readiness. A process environment value with the same name takes precedence. Keep package-specific path values in the local configuration, not in the shared example.

If `isos` reports a configuration error, read the file path and line or field in the error. Correct that file, then run `isos --help` or `isos status --json` again. An `active.env` error such as `unsupported key MUJOCO_ROOT` means remove that key from `~/.config/isos/active.env`; package-specific values belong to the package owner. Keep the file owner-only with `chmod 600 ~/.config/isos/active.env`. A malformed TOML error names the selected `ISOS_CONFIG` file. If `ISOS_CONFIG` points to a missing file, either create it or unset that variable.
